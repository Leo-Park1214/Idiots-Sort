# Idiots Sort

> Sorting algorithms made by an idiot, for idiots, with absolutely no practical value.

**Idiots Sort** is a collection of intentionally cursed, emotionally unstable, and academically irresponsible sorting algorithms.

These algorithms technically exist.  
Whether they should exist is a completely different question.

## What is this?

This repository contains joke sorting algorithms that pretend to sort your list while actively making your life worse.

Currently included:

- `hallucination_sort`
- `menhera_sort`
- `alpha_male_sort`

Each algorithm has its own unique personality, failure mode, and questionable relationship with computer science.
